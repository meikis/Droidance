# Code of Conduct

Everyone participating in Droidance is expected to help maintain a respectful, inclusive community.

Be considerate, discuss technical disagreements constructively, and respect privacy and consent. Harassment, discrimination, threats, sexualized conduct, targeted abuse and publication of private information are unacceptable.

Maintainers may edit or remove inappropriate contributions and restrict participation. Decisions should be proportionate, explain the relevant conduct, and avoid retaliation against people who report concerns in good faith.

Report concerns privately through the repository's GitHub private vulnerability reporting channel, described in SECURITY.md. Do not post private reports or identifying details in public issues. If a maintainer is involved, contact another uninvolved maintainer through an available private GitHub channel. Reports will be reviewed confidentially to the extent needed for a fair investigation.

This policy applies to repository discussions, issues, pull requests and other community spaces, and to conduct while representing this project.
